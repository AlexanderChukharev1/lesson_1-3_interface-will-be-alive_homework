# ДЗ 3. Make it click

Домашняя работа по семинару **1-3 «JavaScript и DOM: интерфейс начинает действовать»**.

Вам предстоит превратить готовую статическую страницу в интерактивную коллекцию: добавить выбор карточек, фильтрацию, счетчик, случайный выбор, сброс, состояния и CSS-анимацию.

## С чего начать

1. Прочитайте [полное описание домашней работы](docs/HOME_WORK.md).
2. Сделайте fork репозитория и создайте рабочую ветку `homework-3`.
3. Откройте [стартовый проект](project/index.html) через Live Server.
4. Выберите тему и замените демонстрационные карточки.
5. Выполняйте этапы по порядку и проверяйте каждый сценарий в браузере.

## Структура

```text
.
├── docs/
│   └── HOME_WORK.md
├── project/
│   ├── index.html
│   ├── styles.css
│   └── script.js
├── AGENTS.md
├── CLAUDE.md
└── README.md
```

Страница уже сверстана. Основная работа выполняется в `project/script.js`; в HTML нужно заменить демонстрационное содержание и настроить `data-*`, а в CSS — осмысленно изменить или добавить анимацию.

## Результат

К моменту сдачи должны быть доступны:

- замерженный pull request в `master` собственного fork;
- опубликованная через GitHub Pages страница по адресу с `/project/`;
- заполненный итоговый чек-лист;
- код, который вы можете объяснить и изменить по небольшому новому условию.
