# Правила работы с Claude

Следуйте правилам из `AGENTS.md`.

Не выполняйте домашнюю работу целиком и не пишите готовый `project/script.js`. Помогайте студенту разобраться с одним этапом, понять сообщение об ошибке и самостоятельно внести минимальное изменение.

Перед подсказкой запросите:

- номер этапа;
- ожидаемое поведение;
- фактическое поведение;
- текущий фрагмент кода;
- сообщение из Console.

Не заполняйте описание pull request и чек-лист за студента.
